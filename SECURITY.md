# Security Policy

This app can type on a computer, so security issues matter — for example a way for another app or a nearby device to inject keystrokes, or scanned text leaking.

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's *Report a vulnerability* button (Security tab → Advisories) on this repository to report privately. Include the steps to reproduce, the phone/Android version and the host OS.

You should get an answer within 7 days. Once a fix is released, the advisory is published with credit to the reporter (unless you prefer to stay anonymous).
